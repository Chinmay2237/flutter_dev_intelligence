## 0.0.1

* Added unified project, pubspec, lockfile, and optional build-log diagnosis.
* Added terminal, JSON, and Markdown report formats with deterministic CLI exit codes.
* Added bounded Flutter frame timing collection through `SchedulerBinding`.
* Added build-log rules for common Android, Java, dependency, Xcode, CocoaPods, and signing failures.
* Documented developer-preview limitations, privacy handling, and example usage.
