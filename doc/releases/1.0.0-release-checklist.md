## 3. Known Limitations

1. **Static AST Analysis**: Static analysis does not execute Flutter runtime widget layout math; confidence scores reflect AST heuristics.
2. **DevTools Trace Sampling**: DevTools traces are capped at 50,000 events to prevent memory overflow on large traces.
3. **Log Slicing**: Build log parsing truncates logs > 10MB to a 2.5MB head + 2.5MB tail slice.
4. **Auto-Fix Preview**: Automated fixes require explicit user preview (`--dry-run`) and manual confirmation before applying edits to disk.
